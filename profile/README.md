## The Project

| 흐름 | 서비스 기능 |
| --- | --- |
| **Order** | 상품 구매와 주문 스냅샷 |
| **Pay** | PortOne·포인트 복합 결제 |
| **Recover** | 환불·포인트 이력·정기 구독 |

`Java 17` `Spring Boot` `MySQL` `PortOne V2` `React`

## My Contribution

포인트 API와 환불 도메인, PortOne V2 인프라 클라이언트를 구현했습니다. 환불의 외부 API 호출과 DB 트랜잭션 분리, 포인트 동시성 처리, 관련 테스트와 프론트엔드 구현에도 참여했습니다.
